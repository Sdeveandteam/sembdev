Security Verification PoC

Clickjacking Frame Embedding Test

Simulasi pemuatan target https://sembdev.my.id ke dalam elemen <iframe> eksternal.

Hasil Pengujian:
Jika browser menampilkan pesan error seperti "Refused to display in a frame" atau elemen di atas tetap kosong, hal ini membuktikan bahwa server/edge target telah mengimplementasikan header X-Frame-Options: DENY / SAMEORIGIN atau CSP frame-ancestors dengan benar.
