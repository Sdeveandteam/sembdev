Panduan Instalasi SAST & DAST Security Scanner (Termux, Ubuntu, Linux)

2026-07-26 • Tool Documentation • Oleh Sdeveandteam

Berikut adalah panduan langkah demi langkah cara menginstal dan menjalankan SAST & DAST Security Scanner dengan AI Explainer di berbagai lingkungan CLI, baik Termux (Android), Ubuntu, maupun Distro Linux lainnya.

1. Persyaratan Sistem (Prerequisites)

Pastikan sistem kamu sudah memiliki Git dan Python 3 terinstal:

  • Python version 3.8+
  • Git CLI
  • Koneksi internet untuk mengunduh dependency

2. Cara Install di Termux (Android)

Buka aplikasi Termux lalu jalankan perintah berikut secara berurutan:

# Update package list & install depedency dasar pkg update && pkg upgrade -y
pkg install git python clang make -y

# Clone repository scanner git clone https://github.com/Sdeveandteam/sdev-toolkit.git
cd sdev-toolkit

# Install module python yang dibutuhkan pip install -r requirements.txt

3. Cara Install di Ubuntu / Debian / Arch Linux

Untuk pengguna Linux PC atau Server (VPS):

# Install git & python3-pip (Ubuntu/Debian) sudo apt update && sudo apt install git python3 python3-pip -y

# Clone repository git clone https://github.com/Sdeveandteam/sdev-toolkit.git
cd sdev-toolkit

# Install requirements pip3 install -r requirements.txt

4. Cara Menjalankan Tool

Setelah instalasi selesai, kamu bisa langsung menjalankan scanning dengan perintah berikut:

# Scan Source Code / Repository (SAST Mode) python main.py --mode sast --path /path/to/your/code

# Scan Web/URL Berjalan (DAST Mode) python main.py --mode dast --url https://target-site.com

# Jalankan dengan AI Explainer python main.py --mode sast --path . --ai-explain
💡 Tips Termux: Jika mengalami error saat instalasi module pip, pastikan kamu sudah menjalankan pkg install clang make terlebih dahulu di Termux.
